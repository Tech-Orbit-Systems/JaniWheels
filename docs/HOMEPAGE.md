# Homepage implementation status

The homepage redesign uses only functionality that is currently operational.
Unavailable modules stay hidden so the interface does not contain dead links,
fake counts or controls that do not persist user data.

## Implemented on the homepage

- Cars, bikes and auto-parts category search
- Existing make, model, category, city, price and year filters
- Existing car body-type facets
- Latest active listings for all three verticals
- Seller type and recorded verified-dealer status
- Verified-dealer section when verified dealer records exist
- Vehicle inspection request
- Post-an-ad calls to action
- Existing trust, reporting and moderation messaging
- Popular model, city and make links for internal SEO navigation
