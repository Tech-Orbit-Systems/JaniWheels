# Home visual asset sources

The popular-search cards use local copies so the home page does not depend on
third-party image availability. City photographs were resized and cropped to
720 × 420 WebP for this interface. Manufacturer marks remain the property of
their respective trademark owners and are used only to identify browse links.

## City photographs

- Karachi — “Mazar-e-Quaid”, Wikimedia Commons.
- Lahore — “Minar-e-Pakistan 2011”, Wikimedia Commons.
- Islamabad — “Faisal Mosque, Islamabad III”, Wikimedia Commons.
- Rawalpindi — “Rawalpindi Railway Station - 01”, Wikimedia Commons.
- Faisalabad — “Clock Tower Faisalabad” by Usman Nadeem, Wikimedia Commons.
- Multan — “Shrine Shah Rukn-e-Alam”, Wikimedia Commons.
- Peshawar — “Islamia College Peshawar”, Wikimedia Commons.
- Gujranwala — “Nishan-E-Manzil Gujranwala 20140925”, Wikimedia Commons.

Each source file and its current licence can be reviewed from its file page on
[Wikimedia Commons](https://commons.wikimedia.org/).

## Manufacturer building photographs

The make grid uses showroom or head-office photographs in which the brand sign
is visible. The Honda, Toyota and MG source photographs were supplied by the
project owner. Suzuki uses the Suzuki Angers dealership photograph from the
manufacturer's French dealer network. Kia uses the Kia America headquarters
photograph from Kia's official careers page. Hyundai uses the Capitol Hyundai
dealership photograph, selected because the original facade signage remains
clear at card size. Changan uses a Pakistan showroom photograph published by
PakWheels, where the original `CHANGAN AUTO` facade signage remains visible.
Nissan uses a Nissan Global Headquarters photograph. Every card is stored
locally as a 720 × 420 WebP so it does not depend on a third-party server at
page-load time.

Haval remains omitted because a suitable verified building photograph is not
available in the local asset set; the next supported popular make is shown.

## Model photographs

The current visual grid uses Toyota Corolla, Suzuki Alto, Honda Civic, Suzuki
Cultus, Honda City, Kia Sportage, Toyota Yaris and Suzuki Swift. Current
Pakistan-market Corolla and the original Yaris reference come from Toyota
Indus; Alto, Cultus and Swift come from Pak Suzuki. Current-generation Civic,
City and Sportage reference photographs are Wikimedia-hosted page images. The
Yaris reference was edited with OpenAI ImageGen to retain the current model
while replacing its neon backdrop with a light neutral studio background.
Local copies were cropped or contained within 640 × 360 WebP cards.
Discontinued Wagon R and Mehran were removed from this current-model grid.
